# Security

Report vulnerabilities in this SDK or in the Mimir program privately through [GitHub security advisories](https://github.com/QuantuLabs/mimir-sdk/security/advisories/new). Do not open a public issue.

Include the affected version, the steps to reproduce and the impact.

Mimir's onchain safeguards are described in the [security page](https://mimirfeeds.io/docs/security.html).

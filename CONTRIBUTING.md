# Contributing

```bash
npm ci
npm run build
npm run typecheck
npm test
```

- Node.js 24 is used in CI; the package supports Node.js 20.18 and later.
- Open an issue before a large change.
- Pull requests need a green CI and a test for any behavior change.
- Never commit keys, keypairs or RPC URLs that contain an API key.

By contributing, you agree that your contributions are licensed under Apache-2.0.
